# Red Night | SCP RP — экран загрузки для Garry's Mod

Готовый экран загрузки (loading screen) для сервера **Red Night | SCP RP**.
Тёмная красно-ночная эстетика SCP RP без «Зоны»: без логотипов Зоны, секторов
и станций — только аномальная ночь, красный уровень угрозы и живой прогресс
загрузки, который Garry's Mod обновляет сам.

```
index.html                 страница загрузчика (то, что видят игроки)
css/style.css              оформление: фон, сканы, зерно, HUD, анимации
css/fonts.css              локальные шрифты (без Google CDN)
js/loading.js              логика: GMod-колбэки, прогресс, демо-режим, частицы
assets/img/*.jpg           фотографии фона (Pexels, свободная лицензия)
assets/fonts/*.woff2       Oswald + JetBrains Mono (кириллица + латиница)
gmod/lua/autorun/server/   аддон, который прописывает sv_loadingurl на сервере
```

Сборка не нужна: это статические файлы. Никаких CDN, трекеров и внешних
запросов — всё лежит рядом со страницей, поэтому экран одинаково работает
в HTML-панели Garry's Mod и в обычном браузере.

## 1. Выложить страницу

Загрузите папку на любой статический хостинг с **публичным HTTPS**-адресом:

- Cloudflare Pages / GitHub Pages / Netlify / Vercel — просто укажите корень проекта;
- свой веб-сервер — положите файлы в каталог сайта (nginx/apache).

Проверка: откройте адрес в браузере. Должны появиться «RED NIGHT», бегущая
строка и демонстрационный прогресс (он включается, когда страницу открывают
вне Garry's Mod — так удобно проверять оформление).

## 2. Подключить к серверу

Самый простой способ — одна строка в `garrysmod/cfg/server.cfg`:

```cfg
sv_loadingurl "https://ваш-домен.ru/?map=%m&steamid=%s"
```

Кавычки обязательны. `%m` и `%s` Garry's Mod заменит на текущую карту и
SteamID64 подключающегося игрока. Если параметры не нужны, можно оставить
просто `sv_loadingurl "https://ваш-домен.ru/"` — имя карты и SteamID всё равно
придут через `GameDetails`.

Альтернатива — консоль сервера или параметр запуска:

```
+sv_loadingurl "https://ваш-домен.ru/?map=%m&steamid=%s"
```

### Вариант с аддоном

В папке `gmod/` лежит готовый серверный аддон:

```
garrysmod/addons/rednight_loading/lua/autorun/server/rednight_loading.lua
```

1. Скопируйте `gmod/lua` в `garrysmod/addons/rednight_loading/`.
2. Укажите свой адрес в переменной `FALLBACK_URL` (или задайте конвар
   `rednight_loadingurl` в `server.cfg`).
3. Перезапустите сервер — адрес применится при старте и после смены карты.

## 3. Что поддерживается из API Garry's Mod

| Колбэк движка | Что показывает экран |
| --- | --- |
| `GameDetails(servername, url, map, maxplayers, steamid, gamemode)` | имя в заголовке, карта, режим, SteamID |
| `SetFilesTotal(n)` | всего файлов |
| `SetFilesNeeded(n)` | прогресс-бар, процент и счётчик скачанных файлов |
| `DownloadingFile(name)` | имя текущего файла |
| `SetStatusChanged(status)` | строка этапа подключения |

Пока движок не передал данные, полоса работает в режиме «ожидание», а после
первого колбэка переключается на реальный прогресс. Демо-прогресс в клиенте
Garry's Mod не включается — он предназначен только для предпросмотра в браузере.

## 4. Настройка под себя

- **Название/тексты** — `index.html` (заголовок `RED NIGHT`, подпись `SCP RP`,
  слоган, бегущая строка, советы внизу — массив `TIPS` в `js/loading.js`).
- **Фотографии** — замените файлы в `assets/img/` с теми же именами или
  поправьте `background-image` у слоёв `.bg-img`.
- **Цвета** — красный акцент `#ff2b33`, глубокий `#c81420`, фон `#050203`.
- **Частота смены фона** — `7200` мс в `js/loading.js` (`setInterval(nextSlide, …)`).
- **Советы** — массив `TIPS` и интервал `6500` мс.
- **Кэш** — после правок добавьте версию к адресу: `.../?v=2&map=%m&steamid=%s`.

## 5. Если экран не появился

1. Адрес открывается в браузере без входа и по HTTPS? Локальный `localhost`
   и `file://` у игроков не работают.
2. В `server.cfg` URL в кавычках, без пробелов и переносов строки.
3. Конвар применился до подключения игрока (перезапуск сервера / смена карты).
4. Клиент мог закэшировать старую страницу — смените адрес (`?v=2`).
5. Проверьте, что сервер не переопределяет `sv_loadingurl` в другом конфиге.
