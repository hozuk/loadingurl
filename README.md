# Red Night | SCP RP: экран загрузки для Garry's Mod

Экран загрузки для сервера Red Night | SCP RP. Фон из четырёх фотографий с красной подсветкой, сканлайны, зерно плёнки и HUD с процентом, именем файла, картой и SteamID. Логотипов Зоны, секторов и станций нет.

Файлы проекта:

```text
index.html                 страница загрузчика, её видят игроки
css/style.css              оформление: фон, сканы, зерно, HUD, анимации
css/fonts.css              локальные шрифты
js/loading.js              колбэки Garry's Mod, прогресс, демо-режим, частицы
assets/img/*.jpg           фотографии фона с Pexels
assets/fonts/*.woff2       Oswald и JetBrains Mono, кириллица и латиница
gmod/lua/autorun/server/   аддон, который прописывает sv_loadingurl
```

Сборка не нужна. Это статические файлы. Шрифты и фото лежат рядом со страницей и не запрашиваются с чужих серверов, поэтому страница работает и в HTML-панели Garry's Mod, и в браузере.

## 1. Выложить страницу

Загрузите папку на статический хостинг с публичным HTTPS: Cloudflare Pages, GitHub Pages, Netlify, Vercel или свой nginx. Затем откройте адрес в браузере. Появятся заголовок, бегущая строка и демонстрационный прогресс. Демо включается только вне Garry's Mod, так удобно проверять оформление.

### Автопубликация через GitHub Actions

В репозитории лежит workflow `.github/workflows/pages.yml`. Он собирает папку `_site` из `index.html`, `css/`, `js/` и `assets/` и публикует её на GitHub Pages при каждом пуше в `main`. Запустить вручную можно через Actions → Deploy loading screen → Run workflow.

GitHub требует один раз указать источник публикации. В Settings → Pages выберите Source: `GitHub Actions`. Если Pages ещё не включён, то же самое делает одна команда с правами администратора репозитория:

```bash
gh api -X POST repos/hozuk/loadingurl/pages -f build_type=workflow
```

После первого успешного запуска сайт будет доступен по адресу `https://hozuk.github.io/loadingurl/`. Дальше каждый коммит в `main` обновляет страницу автоматически.

## 2. Подключить к серверу

Добавьте строку в `garrysmod/cfg/server.cfg`:

```cfg
sv_loadingurl "https://ваш-домен.ru/?map=%m&steamid=%s"
```

Кавычки обязательны. Garry's Mod заменит `%m` на текущую карту, а `%s` на SteamID64 подключающегося игрока. Без параметров тоже работает: карта и SteamID придут через `GameDetails`.

Тот же конвар можно задать в консоли сервера или параметром запуска:

```
+sv_loadingurl "https://ваш-домен.ru/?map=%m&steamid=%s"
```

### Вариант с аддоном

В папке `gmod/` лежит серверный аддон:

```
garrysmod/addons/rednight_loading/lua/autorun/server/rednight_loading.lua
```

1. Скопируйте `gmod/lua` в `garrysmod/addons/rednight_loading/`.
2. Укажите свой адрес в переменной `FALLBACK_URL` или задайте конвар `rednight_loadingurl` в `server.cfg`.
3. Перезапустите сервер. Адрес применится при старте и после смены карты.

## 3. Что поддерживается из API Garry's Mod

| Колбэк движка | Что показывает экран |
| --- | --- |
| `GameDetails(servername, url, map, maxplayers, steamid, gamemode)` | имя в заголовке, карта, режим, SteamID |
| `SetFilesTotal(n)` | всего файлов |
| `SetFilesNeeded(n)` | прогресс-бар, процент, счётчик скачанных файлов |
| `DownloadingFile(name)` | имя текущего файла |
| `SetStatusChanged(status)` | строка этапа подключения |

До первого колбэка полоса работает в режиме ожидания. После него показывается реальный прогресс. Демо-прогресс в клиенте Garry's Mod не включается, он нужен только для предпросмотра в браузере.

## 4. Настройка под себя

Тексты лежат в `index.html`: заголовок `RED NIGHT`, подпись `SCP RP`, слоган, бегущая строка и подписи HUD. Советы внизу собраны в массиве `TIPS` в `js/loading.js`.

Фотографии замените в `assets/img/` с теми же именами или поправьте `background-image` у слоёв `.bg-img`.

Красный акцент имеет цвет `#ff2b33`, глубокий красный `#c81420`, фон `#050203`.

Интервал смены фона задаёт `setInterval(nextSlide, 7200)` в `js/loading.js`. Интервал советов задаёт `6500` в конце того же файла.

После правок добавьте версию к адресу, чтобы клиенты не взяли старую страницу из кэша: `.../?v=2&map=%m&steamid=%s`.

## 5. Если экран не появился

1. Адрес открывается в браузере без входа и по HTTPS? Локальный `localhost` и `file://` у игроков не работают.
2. URL в `server.cfg` стоит в кавычках, без пробелов и переносов строки.
3. Конвар применился до подключения игрока: перезапустите сервер или смените карту.
4. Клиент мог закэшировать старую страницу: смените адрес, например на `?v=2`.
5. Сервер не переопределяет `sv_loadingurl` в другом конфиге.
